### 28. Простая ролевая боевая система

## Описание реализации

**Структурный стиль (`structural.py`):** персонаж — это словарь с полями
`name`, `health`, `max_health`, `attack`, `defense`. Вся логика (расчёт
урона, применение урона, проведение хода, симуляция всего боя) вынесена
в отдельные функции, которые принимают словари как аргументы. Данные и
поведение разделены — функции не привязаны к конкретному объекту.

**ООП-стиль (`oop.py`):** класс `Character` инкапсулирует характеристики
персонажа и умеет атаковать (`attack_target`) и получать урон
(`take_damage`). Класс `Battle` отвечает за проведение раундов боя,
ведение лога и определение победителя — то есть логика боя вынесена в
отдельный объект-"судью", а не размазана по персонажам.

Оба варианта используют одинаковую формулу урона
(`max(1, атака_атакующего − защита_защищающегося)`), одинаковый порядок
ходов (персонажи бьют по очереди, начинает первый) и дают идентичный
результат на одинаковых входных данных.
